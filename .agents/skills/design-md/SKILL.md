# design.md generation

## When
Small features, new skills, or “should we build X?” notes — not 20-page PRDs.

## Output
Write `out/design-<slug>.md`:

```markdown
# <Title>
## Problem
## Proposal
## Interfaces / APIs
## Risks
## Ship checklist
```

Keep under ~1 page. Link any skills or endpoints involved.
